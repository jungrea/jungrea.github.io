用户询问：

> Vercel — 零配置，git push 自动部署
> Cloudflare Pages — 同上
> Netlify — 同样支持
> GitHub Pages — 免费，需要配一下 workflow
> 
> 这几个哪些都是有对外域名的吗

这属于项目部署事实查询，后续回答需要明确各平台是否默认提供公共子域名（如 *.vercel.app、*.pages.dev、*.netlify.app、<username>.github.io），以及是否支持自定义域名。
